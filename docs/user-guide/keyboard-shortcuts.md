# Keyboard Shortcuts

Complete reference for all keyboard shortcuts in Kanban AI.

## Overview

Kanban AI is designed for keyboard-first workflows. Most actions can be performed without using the mouse.

!!! tip "Shortcut Notation"
    - `Cmd` = Command (Mac) / Ctrl (Windows/Linux)
    - `Opt` = Option (Mac) / Alt (Windows/Linux)
    - `Shift` = Shift key
    - `+` = Press keys together

---

## Customization

### Viewing Current Shortcuts

1. Press `Cmd+?` to open shortcuts reference
2. Or go to **Settings > Keyboard**

### Customizing Shortcuts

1. Go to **Settings > Keyboard > Customize**
2. Click the shortcut you want to change
3. Press your new key combination
4. Click **Save**

!!! warning "Reserved Shortcuts"
    Some system shortcuts cannot be overridden:

    - `Cmd+Q` - Quit application
    - `Cmd+W` - Close window
    - `Cmd+Tab` - Switch apps

### Resetting Shortcuts

1. Go to **Settings > Keyboard**
2. Click **Reset to Defaults**
3. Confirm reset

## Tips for Keyboard Efficiency

1. **Learn the Command Palette** - `Cmd+K` gives access to everything
2. **Use Quick Priority** - `1-4` is faster than opening menus
3. **Navigate with Arrows** - Avoid mouse for ticket selection
4. **Chain Commands** - Use `/` then filters for quick searches
5. **Customize Your Workflow** - Remap shortcuts to your preferences
